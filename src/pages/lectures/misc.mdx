## SG-Value
對每個狀態，他的 SG-Value 是他走得到的狀態的 Mex

SG Value = 0 iff 先手必敗

## SG Theorem
對多個遊戲，先手必敗 iff xor of 所有遊戲的 SG Value 是 0

基本上可以想成把所有的遊戲都當成一堆石頭的 nim 來玩

賽局題通常有兩種作法：一種是當個數學家，用瞪的瞪出最後的結論，把他當結論題做；另一種是打表，反正 SG Value 這東西跑起來是 $O(n^2)$ 的可以至少讓你打個幾十個人來對照

# 互動題
就丟幾題不錯的互動題吧

互動題通常可以當成會卡常數的演算法題，因為通常都是限定詢問次數，所以比較不存在什麼複雜度多一個 log 還會過這種事情

或者是單純是把一些經典演算法用互動題包裝讓他看起來很難
