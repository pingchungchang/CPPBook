## Euler Circuit
之前忘記講的歐拉迴路

一張圖有歐拉回路(euler cycle) iff
- 連通
- 每個點度數都是偶數

找歐拉迴路：
```cpp
vector<pii> paths[mxn]; // first: to, second: edge id
int idx[mxn];
bool vis[mxm];
vector<int> eul;

void dfs(int now) {
    for (int &i = idx[now]; i < paths[now].size(); i++) {
        if (vis[i]) continue;
        auto [nxt, eid] = paths[i];
        vis[eid] = true;
        dfs(nxt);
        eul.push_back(now);
    }
    return;
}

void euler() {
    dfs(1);
}
```

啊要找 euler path 就是固定起點就好了
